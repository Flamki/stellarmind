HTTP 402 Payment Required is a status code reserved in the HTTP specification for payment flows, but it went largely unused for decades because the web lacked a native way to move small amounts of money. Protocols such as x402 revive it: a server answers an unpaid request with 402 and a machine-readable price, and the client retries with a signed payment attached. This lets software agents pay per call, for example a fraction of a cent per request, without accounts, subscriptions or API-key billing. Settlement speed and fees matter, because a payment that costs more than the request itself defeats the purpose. Networks that close ledgers in about 5 seconds make this practical for low-value calls.
